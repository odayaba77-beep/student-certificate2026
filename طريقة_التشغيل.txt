دليل تشغيل نظام إدارة الدرجات والمراكز الأكاديمية على جهازك
================================================================

لماذا تظهر "شاشة بيضاء" عند الضغط المباشر على ملف index.html؟
------------------------------------------------------------
المشروع مبني بأحدث تقنيات الويب الحديثة (React 19 + TypeScript + Vite).
ملف index.html يحتوي على أكواد برمجية وموديولات (type="module")، ومتصفحات
الإنترنت (مثل Google Chrome و Edge) تمنع أمنياً تشغيل هذه الملفات عند النقر
المباشر (file:///)، وتتطلب تشغيل خادم محلي بسيط أو معالجتها أولاً.


كيفية تشغيل النظام على جهازك بسهولة:
----------------------------------
الخطوة 1: تثبيت Node.js (لمرة واحدة فقط):
- حمّل وثبّت البرنامج المجاني Node.js من الرابط الرسمي:
  https://nodejs.org
  (اختر النسخة LTS المستقرة).

الخطوة 2: تشغيل النظام (بنقرة زر واحدة):
- اضغط مرتين (Double Click) على الملف:
  "تشغيل_النظام.bat" أو "start.bat"
- سيقوم الملف تلقائياً بتجهيز المكتبات وفتح المتصفح على النظام فوراً!


أو التشغيل اليدوي عبر موجه الأوامر (CMD / Terminal):
--------------------------------------------------
1. افتح موجه الأوامر داخل مجلد المشروع.
2. اكتب الأمر التالي واضغط Enter:
   npm install
3. ثم اكتب:
   npm run dev
4. افتح المتصفح على العنوان التالي:
   http://localhost:3000
